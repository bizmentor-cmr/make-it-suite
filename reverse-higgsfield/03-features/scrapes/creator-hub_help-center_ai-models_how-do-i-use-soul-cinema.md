# How do I use Soul Cinema?

Copy page

HiggsfieldAug 1, 20262 min

Soul Cinema is Higgsfield's cinematic image model. It produces images with deep textures, rich atmosphere, and a look that avoids the typical AI aesthetic. Unlike Soul 2.0, it has no preset panel or Moodboard. The cinematic style is built into the model. You can apply a Soul HEX color palette and a Soul ID character.

## What is [Soul Cinema](https://higgsfield.ai/soul-cinema)?

Soul Cinema is a separate model in the Soul family, focused on cinematic-grade output: close-up shots with atmospheric mood, rich textures, and a spontaneous quality. It works especially well as a starting point for AI video, for example as a keyframe input for Kling or Seedance.

Soul Cinema has no presets or Moodboards. The cinematic aesthetic is built into the model itself. Color control through Soul HEX and character consistency through Soul ID are both supported.

## How is Soul Cinema different from Soul 2.0?

| Criteria | Soul 2.0 | Soul Cinema |
| --- | --- | --- |
| Presets | Yes | No |
| Moodboards | Yes | No |
| Soul HEX | Yes | Yes |
| Soul ID | Yes, shared across the family | Yes, shared across the family |
| Prompt with reference image | No | No |
| Built-in aesthetic | Fashion-aware, culture-native | Cinematic, atmospheric |
| Best for | Full creative control | Cinematic output, video keyframes |

## How do I generate with Soul Cinema?

Path: [higgsfield.ai](https://higgsfield.ai/) → Image → [Soul Cinema](https://higgsfield.ai/ai/image?model=soul-cinematic)

1. Write a prompt describing the scene, subject, and mood.
2. Optionally apply a Soul HEX color palette via Color Transfer.
3. Optionally select a Soul ID character.
4. Set aspect ratio, quality, and batch size.
5. Click Generate.

When a reference image is attached, the prompt field becomes unavailable. You can still apply a Soul ID character and a Soul HEX palette alongside the reference.

## Can I use a Soul 2.0 character in Soul Cinema?

Yes. A trained Soul ID works across the Soul family. Open the Character panel while on Soul Cinema and select your existing character: if an update option appears, run it, and the character becomes available in Soul Cinema.

## What is Soul Cinema best for?

Close-up portraits with cinematic mood, atmospheric scenes with rich texture, editorial-style visuals where the cinematic look matters more than stylistic variety, and starting keyframes for AI video generation.

## Got any questions left?

Does Soul Cinema have presets?

No. The cinematic aesthetic is built into the model. There is no preset or Moodboard panel.

Can I use Soul HEX in Soul Cinema?

Yes. Click Color Transfer to apply a color palette from a reference image or choose a built-in palette.

Can I write a prompt and use a reference image at the same time?

No. When a reference image is attached, the prompt field is unavailable.

Is Soul Cinema good for video keyframes?

Yes. Its cinematic output works well as a starting image for Kling or Seedance.

How many images can I generate at once?

Up to 4 per generation. Set the batch size in the generation bar before clicking Generate.
