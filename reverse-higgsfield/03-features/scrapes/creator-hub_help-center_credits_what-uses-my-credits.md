# What uses my credits?

Copy page

HiggsfieldAug 3, 20262 min

Credits don't disappear without a logged reason. Check your usage history first: it logs every deduction with the model and timestamp. The most common causes are a subscription reset at renewal, generations through MCP or CLI, multiple outputs from one prompt.

## How do I check where my credits went?

1. Click your avatar in the top right corner and select **Manage Account**.
2. Open **Usage** in the left sidebar.

Credits Usage History shows every credit operation: deductions, refunds, the model used, and a timestamp. Check this before contacting Support, the reason is almost always there. For full detail on what the log includes, see [How do credits work?](https://higgsfield.ai/creator-hub/help-center/credits/how-credits-work)

## What are the most common reasons credits disappear?

| **What happened** | **How to confirm** |
| --- | --- |
| **Subscription credits reset at renewal.** They reset every billing cycle and don't roll over | Check your renewal date: **Manage Account** → **Subscription**, the date is at the top under your plan name |
| **Credits spent outside the website.** Generations through MCP, CLI, Canvas, Supercomputer, and other automated tools always deduct credits, even for models with Unlimited access on the web | Generations from connected agents appear in your usage history tagged with the source |
| **Multiple outputs from one prompt.** If you set the batch size to 2, 3, or 4 before generating, each output is charged separately | The total cost is shown on the Generate button before you confirm |
| **A failed generation didn't return credits.** Most failed generations return credits automatically | Look for the return in your usage history; if it's missing, contact Support |

## Got any questions left?

Why did my balance go down when I wasn't generating?

The most common reason is a subscription reset: at each renewal, unused subscription credits expire and a new allowance is added. Your usage history ( **Manage Account** → **Usage**) shows the exact operation behind any change. If the deduction isn't explained there, contact Support.

Credits were deducted for a generation that failed. Will I get them back?

Failed generations return credits automatically. If the refund doesn't appear in your usage history, contact Support through [higgsfield.ai/contact](http://higgsfield.ai/contact).

I used MCP and my credits dropped faster than expected. Is that normal?

Yes. Unlimited access and free generations apply only on [higgsfield.ai](https://higgsfield.ai/). Any generation made outside it, including through MCP, CLI, Canvas, Supercomputer, and other automated tools, always deducts credits.

I generated one image but lost more credits than expected. Why?

Check the batch size you selected before generating: if it was set to 2, 3, or 4, each output is charged separately. The total cost for the selected batch is shown on the Generate button before you confirm.
