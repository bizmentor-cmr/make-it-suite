# How do I use Soul to generate images?

Copy page

HiggsfieldAug 1, 20263 min

Soul is how Higgsfield handles fashion-aware, culture-native image generation. The family includes three models: Soul for quick preset-driven generation, Soul 2.0 for full creative control with Moodboards, Soul HEX, and reference images, and Soul Cinema for cinematic-grade visuals.

## What is the Soul family?

| Model | Best for | Key features |
| --- | --- | --- |
| Soul | Quick preset-driven generation | Style presets, avatar support |
| Soul 2.0 | Full creative control | Presets, Moodboard, Soul HEX, Soul ID, reference image |
| Soul Cinema | Cinematic-grade visuals | Soul HEX, Soul ID, cinematic style built in |

What is the Soul family?

## How do I generate with [Higgsfield Soul](https://higgsfield.ai/soul)?

Path: [higgsfield.ai](http://higgsfield.ai/) → Image → Soul

Select a preset from the preset panel. Categories include General, TikTok Core, Instagram Aesthetics, Beauty, Mood, Camera Photo, and Graphic Art. Write a prompt or leave it empty, set your batch size and aspect ratio, and click Generate.

You can also generate with an avatar. Select one from the Character section, choose a preset, and generate.

## How do I generate with [Higgsfield Soul 2.0](https://higgsfield.ai/soul-intro)?

Path: [higgsfield.ai](http://higgsfield.ai/) → Image → Soul 2.0

Soul 2.0 gives you more control. You can combine a prompt, a preset or Moodboard, a Soul ID character, and a Soul HEX color palette in the same generation.

Without a reference image, all inputs are available together: prompt, preset or Moodboard, Soul ID, and Soul HEX.

With a reference image, the prompt field becomes unavailable. Soul 2.0 uses the reference as the primary direction. You can still apply a Soul ID character and a Soul HEX palette alongside it.

## What are Moodboards?

Moodboards are custom reusable style presets you create from your own reference images. Soul 2.0 analyzes their lighting, texture, contrast, and color to build a style that applies consistently across your generations.

Two types are available: Curated Moodboards (built-in presets like Y2K Studio, Digital Camera, Retro BW) and Personal Moodboards (your own created styles).

To create a Moodboard: Soul 2.0 - Moodboard icon - Build your moodboard - upload from device or from Assets. For a strong style result, aim for 20 or more images in one cohesive aesthetic without faces. Avoid blurry or low-quality images and avoid mixing unrelated styles.

Moodboards are only available in Soul 2.0, not in Soul or Soul Cinema.

## What is Soul HEX?

Soul HEX is a color control tool. Upload a reference image and Soul HEX extracts its dominant color palette, then applies those colors to your generation. Available in Soul 2.0 and Soul Cinema.

To use Soul HEX: click Color Transfer in the generation bar, then upload a reference image or choose from built-in palettes: Film colors, Lime Jam, Candy pink, Nostalgic blue, Soft palette, and Black gloss.

## What is Soul ID?

Soul ID is the character consistency layer. Train it once on photos of one person and the same face appears across every generation. A trained Soul ID works across the Soul family: the same character is available in every Soul model. For full instructions on training a Soul ID character, see [How do I create and use a Soul ID character?](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character)

## What are the generation settings?

| Setting | Options |
| --- | --- |
| Aspect ratio | 9:16, 3:4, 2:3, 1:1, 4:3, 16:9, 3:2 |
| Quality | 1.5k, 2k |
| Batch size | 1 to 4 images |
| Color Transfer | Soul HEX palettes |

## Got any questions left?

Can I use a Soul 2.0 character in Soul Cinema?

Yes. A trained Soul ID works across the Soul family, so the same character is available in every Soul model.

Can I write a prompt when using a reference image?

No. When a reference image is attached in Soul, Soul 2.0, or Soul Cinema, the prompt field becomes unavailable.

What is the difference between presets and Moodboards?

Presets are built-in style options. Moodboards are custom style presets you create from your own reference images. Moodboards are only available in Soul 2.0.

Where is Soul HEX available?

In Soul 2.0 and Soul Cinema only.

How many images can I generate at once?

Up to 4 per generation. Set the batch size in the generation bar before clicking Generate.

Do Soul generations use credits?

Yes, at standard rates, with the cost shown on the Generate button. Some plans include a one-time pool of free generations for Soul models: the exact pools are listed in the Unlimited & Free Gens section of your plan's card on the Pricing page. See [How do credits work?](https://higgsfield.ai/creator-hub/help-center/credits/how-credits-work)
