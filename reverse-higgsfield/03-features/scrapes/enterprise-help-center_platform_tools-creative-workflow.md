# Tools & Workflows

Copy page

Last updatedOct 6, 2026

Cinema Studio, Marketing Studio, Supercomputer, and Canvas - which tool for which job.

Start from the result you need, then pick the tool.

## Choose a tool

| I want to… | Use |
| --- | --- |
| Cinematic video with camera, lens and lighting control | **Cinema Studio** |
| Keep a character consistent across clips | **Cinema Studio + Elements** |
| A product ad or UGC video from a URL or image | **Marketing**<br>**Studio** |
| A consistent AI influencer | **AI Influencer** |
| Connect models in a visual workflow | **Canvas** |
| Run a whole project from one chat, schedule tasks | **Supercomputer** |
| Generate from Claude or a coding agent | **MCP / CLI** |
| Batches of static ads from a catalogue | **Ads Studio** |
| Variants of a working video ad | **Ad Multiplier** |

Choose a tool

## Cinema Studio 4.0

Open **Cinema Studio**. A project keeps the brief, references, Elements, generations and team together.

- **Film setup** and **Camera** \- 30+ camera-movement presets, lens and aperture.
- **Video Lighting Console** and **Color Grading** \- two light sources, 50+ palettes.
- **Acting Console** \- six emotions, three intensities.
- **Elements** \- reusable characters, locations and props.
- **Video Extend** \- continue a clip forward, bridge two scenes or extend backward.

You can create projects in both Cinema Studio and Marketing Studio. Use Cinema Studio for connected scenes and team production; use Marketing Studio for product images, UGC and campaign creatives. Find creation steps, access settings, Elements, folders and usage in [Projects](https://higgsfield.ai/enterprise-help-center/manage-account/projects).

## Marketing Studio

1. Open **Marketing Studio** and paste the product URL. Higgsfield pulls the images, name, features and price.
2. Review the script.
3. Pick a format: **UGC**, **Tutorial**, **Unboxing**, **Product Review**, **TV Spot**, **Hyper Motion**, **Wild Card** or virtual try-on.
4. Add a spokesperson: a library avatar, a custom one, or a trained Soul ID.
5. Set the aspect ratio and click **Generate**. Clips are up to 15 seconds.

Also: **Ad Reference** recreates an existing ad's structure with your product, **Brand Kit** pulls brand details from your site, **DTC Ads** makes static ad images.

### Ad Multiplier

1. Upload a 4–30 second ad. Use it in Supercomputer or Claude through Higgsfield MCP: [higgsfield.ai/ad-multiplier](https://higgsfield.ai/ad-multiplier).
2. Describe what to swap: person, outfit, location, objects or product.

Runs on Seedance 2.5. Keeps the cut, timing, framing and original audio; can remove burned-in captions.

## Ads Studio

Open **Ads Studio** and paste your website. It imports the brand and products, finds selling angles, writes copy and generates batches by SKU, angle and design. Brand and products stay saved. [higgsfield.ai/ads-studio](https://higgsfield.ai/ads-studio).

## Supercomputer

Open **Supercomputer** and describe the deliverable in plain language. The agent plans the task, sends each step to a model, connects apps and assembles the result. Choose the language model. Schedule recurring tasks. It can also build and deploy web apps and games. Each step costs credits at the standard rate; the running cost is shown as it works.

## Canvas

Open **Canvas**. Every model is a node: connect prompt → image → video → edit. Run nodes one by one or in sequence, compare models side by side, save workflows as templates, work on one board together. Building is free; credits are used only when a node generates.

References: describe the reference's role at the start of a Seedance prompt. For a Kling character, create an Element and use its @tag. A directly connected image becomes a start frame.

## AI Influencer

Open **AI Influencer**. Choose the character type, identity and skin; **Advanced settings** adds **Face**, **Body** and **Style** tabs. Characters generate at up to 4K and save to your character library. Animate with **Genjutsu** presets or **Motion Control**. Train a Soul ID with at least 20 photos to reuse the same face in supported Soul models.
