# MCP, CLI & Plugins

Copy page

Last updatedOct 6, 2026

Generate from Claude, coding agents, Figma and Adobe apps with your workspace credits. No API key needed.

## Higgsfield MCP

Connect from Claude.

1. In Claude (web or desktop), open **Settings → Connectors → Add custom connector**.
2. Paste **https://mcp.higgsfield.ai/mcp** and click **Connect**.
3. Sign in to Higgsfield in the window that opens.
4. Start a new chat and ask "What is my Higgsfield credit balance?" to confirm it works.

### What you can do through MCP

Generate images and video; upscale, remove backgrounds, expand; use **Kling Motion Control**, **Soul** characters and **Elements**; create voiceover, voice clones and dubbing; send outputs to folders; run **Ad Multiplier**. Outputs appear in **Assets**. Voice clones: 5 per workspace by default (ask your account manager for more).

## CLI and Skills

1. Install Node.js and the Higgsfield CLI using the [installation guide](https://github.com/higgsfield-ai/skills/blob/main/INSTALL.md).
2. Run `higgsfield auth login`.
3. Run `npx skills add higgsfield-ai/skills`.
4. In Claude Code, Cursor or Codex, ask "Generate an image with Higgsfield".

## Plugins and integrations

- **Figma and FigJam** \- generation, vector SVG, mockups, background removal; Canvas nodes in FigJam.
- **Photoshop** \- **Generate AI Image**, **Realtime AI**, **Layer Decompose**, **Face Swap**, **Upscale**.
- **Premiere Pro and After Effects** \- clips and B-roll to the timeline; **Reframe**, **Remove Background**, **Edit Video**.
- **DaVinci Resolve** \- generation, **Draw to Video**, **Color Match**, import to the Media Pool.
- **Minecraft** mod and **Higgsfield Gaming** (game builder inside Supercomputer).
