# Higgsfield API

Copy pageCopy page

Generate images and videos through one authenticated, asynchronous API.

Copy pageCopy page

Higgsfield provides one integration point for generative media models. Submit a request to a model endpoint, then poll for the result or receive a webhook when processing finishes.

[**Run your first request** \\
\\
Create credentials and complete a generation from submission to result.](https://docs.higgsfield.ai/docs/quickstart)

[**Get an API key** \\
\\
Create and manage server-side credentials in Higgsfield Console.](https://console.higgsfield.ai/)

## [​](https://docs.higgsfield.ai/docs\#make-a-request)  Make a request

Every model uses the same authentication and asynchronous request lifecycle. The JSON body depends on the selected model.Start with [Genjutsu motion transfer](https://docs.higgsfield.ai/docs/models/genjutsu/motion-transfer). Replace the example media URLs with publicly accessible URLs for your own video and reference image. The source video must be at least 4 seconds long.

Genjutsu

SOUL V2

```
curl --request POST \
  --url https://api.higgsfield.ai/higgsfield/genjutsu/motion-transfer/v1.0 \
  --header "Authorization: Key ${HF_API_KEY_ID}:${HF_API_KEY_SECRET}" \
  --header "Content-Type: application/json" \
  --data '{
    "video_url": "https://example.com/input.mp4",
    "image_urls": ["https://example.com/input.jpg"]
  }'
```

```
curl --request POST \
  --url https://api.higgsfield.ai/higgsfield-ai/soul/v2/standard \
  --header "Authorization: Key ${HF_API_KEY_ID}:${HF_API_KEY_SECRET}" \
  --header "Content-Type: application/json" \
  --data '{
    "prompt": "Editorial portrait in soft daylight"
  }'
```

The API immediately returns a request identifier and links for checking or canceling the request.

```
{
  "status": "queued",
  "request_id": "d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff",
  "status_url": "https://api.higgsfield.ai/requests/d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff/status",
  "cancel_url": "https://api.higgsfield.ai/requests/d7e6c0f3-6699-4f6c-bb45-2ad7fd9158ff/cancel"
}
```

## [​](https://docs.higgsfield.ai/docs\#choose-your-path)  Choose your path

[**Build a prototype** \\
\\
Use the Python or TypeScript SDK to submit a request and wait for its result.](https://docs.higgsfield.ai/docs/how-to/sdk)

[**Ship to production** \\
\\
Learn the request lifecycle, polling, webhooks, errors, and limits.](https://docs.higgsfield.ai/docs/concepts/requests)

[**Upload media** \\
\\
Upload input files to Higgsfield storage before generation.](https://docs.higgsfield.ai/docs/concepts/file-uploads)

Output files are available for at least seven days. Download completed output to your own storage for long-term retention.
